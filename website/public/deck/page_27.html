Fathom's architecture is structured as a tightly optimized Rust workspace comprising 12 specialized crates, each with explicit boundary contracts, zero circular dependencies, and dedicated sub-millisecond execution loops.

  • crates/governance: Fail-closed policy engine & AES-256-GCM vault.
Tokio JoinSet Tree Concurrency

Sub-agent lifecycles are managed via tokio::task::JoinSet. When a coordinator dispatches 4 workers, tasks are scheduled across available CPU cores in parallel. If a child agent errors, the parent traps the cancellation token cleanly.

Architectural Cleanliness: Zero circular dependencies; strictly decoupled domain boundaries allow enterprise developers to extend Fathom with custom internal tools in minutes.
