Fault-Tolerant Daemon Architecture: Surviving Server Restarts and Network Outages

Toy agent frameworks crash when terminal sessions disconnect or when third-party APIs return rate limits. Fathom is engineered as a resilient Unix daemon service with automated process detachment, SQLite state hydration, and multi-turn error reflection.

1. Detached setsid Process Management
  • Background Decoupling: Long-running sessions fork into Unix process groups via setsid.
  • Terminal Immunity: SSH disconnects do not interrupt active research swarms or jobs.
  • Signal Trapping: Gracefully handles SIGTERM, flushing CRM writes before shutdown.
2. Durable SQLite State Hydration
  • WAL-Mode Reliability: Every tool execution and lead is written to SQLite with WAL logging.
  • Instant Recovery: On power failure, the daemon reboots in <5ms and resumes from the last step.
  • Zero Corrupted State: Atomic transactions ensure zero orphan records or duplicate outreach.
