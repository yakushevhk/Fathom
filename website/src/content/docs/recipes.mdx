  <section id="tips">
    <div class="section-header">
      <span class="section-badge">Best Practices</span>
      <h2>Tips & Best Practices</h2>
      <p>Hard-won advice from production deployments. These tips help you get better results, avoid common pitfalls, and keep costs under control.</p>
    </div>
    <div class="recipe-grid">
      <div class="recipe-card">
        <h3>Write specific, structured prompts</h3>
        <div class="code-block">
          <div class="code-header"><span class="code-lang">text</span></div>
          <pre><code set:html={`# Vague (low quality results):
"Find leads in fintech"

# Specific (high quality results):
"Find CTOs and VP Engineering at B2B fintech
startups in London with 50-200 employees that
raised Series A or B in the past 18 months.
Verify each email via SMTP probe. Include
company size, last funding round, and tech
stack from job postings."`} /></pre>
        </div>
        <p class="recipe-notes">Specificity drives quality. Include geography, company size, role, verification method, and enrichment fields. The agent performs better with clear success criteria.</p>
      </div>
      <div class="recipe-card">
        <h3>Use -o for reproducibility</h3>
        <div class="code-block">
          <div class="code-header"><span class="code-lang">bash</span></div>
          <pre><code set:html={`# Always specify output directory
fathom run "..." -o ./leads/q1-2025

# Re-run produces deterministic structure
ls ./leads/q1-2025/
# contacts.db  session.json  sources/  synthesis.md`} /></pre>
        </div>
        <p class="recipe-notes">Explicit output directories make results versionable, comparable, and easy to reference in follow-up sessions. The deterministic structure means scripts can reliably process outputs.</p>
      </div>
      <div class="recipe-card">
        <h3>Start shallow, then go deep</h3>
        <div class="code-block">
          <div class="code-header"><span class="code-lang">bash</span></div>
          <pre><code set:html={`# First pass: broad, shallow
fathom run "..." --depth 2 -o ./broad

# Second pass: deep dive on top results
fathom run "Analyze top 20 from ./broad"`} /></pre>
        </div>
        <p class="recipe-notes">Shallow depth is faster and cheaper. Use it to identify the most promising targets, then invest deep research only on the best candidates. This two-pass approach cuts costs by 60-80%.</p>
      </div>
      <div class="recipe-card">
        <h3>Chain sessions with memory</h3>
        <div class="code-block">
          <div class="code-header"><span class="code-lang">bash</span></div>
          <pre><code set:html={`# Session 1: research
fathom run "..." -o ./research

# Session 2: uses memory from session 1
fathom memory distill --session latest
fathom run "Using prior research, ..." -o ./follow-up`} /></pre>
        </div>
        <p class="recipe-notes">Distilling session facts into memory makes them available to future sessions. The memory graph connects entities across sessions, so the second session benefits from all prior context.</p>
      </div>
    </div>
  </section>
