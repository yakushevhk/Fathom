<section id="lsp-overview">
  <h2 data-i18n="docsProtocolGui.lspTitle">LSP integration</h2>
  <p data-i18n="docsProtocolGui.lspP1">Fathom includes an <code>lsp</code> tool for code intelligence. It detects the project language, checks for the matching language server, and connects over stdio — one lazily-spawned client per project root.</p>
  <p data-i18n="docsProtocolGui.lspP2">The tool is registered with the normal tool registry, so workers can call it from <code>fathom run</code>, <code>fathom tui</code>, <code>fathom serve</code>, or expose it to MCP clients via <code>fathom mcp-serve</code>.</p>
</section>
