<div class="doc-header">
    <span class="doc-badge" data-i18n="docsQuickstart.badge">Getting Started</span>
    <h1 data-i18n="docsQuickstart.title">Quickstart</h1>
    <p class="doc-lead" data-i18n="docsQuickstart.lead">
      Get Fathom's universal autonomous worker runtime up and running quickly.
      This guide covers installation, configuration, and your first task session.
    </p>
  </div>

  <section id="prerequisites">
    <h2 data-i18n="docsQuickstart.prereqTitle">Prerequisites</h2>
    <p data-i18n="docsQuickstart.prereqSub">Before installing Fathom, make sure you have:</p>
    <ul class="check-list">
      <li data-i18n-html="docsQuickstart.pre1"><strong>Rust 1.97</strong> — required for building from source (skip if using the curl installer)</li>
      <li data-i18n-html="docsQuickstart.pre2"><strong>API key</strong> — for the DeepSeek OpenAI-compatible endpoint (or another OpenAI-compatible endpoint)</li>
      <li data-i18n-html="docsQuickstart.pre3"><strong>Optional:</strong> Chrome with <code>--remote-debugging-port=9222</code> for browser CDP tools; Python/Node for REPL</li>
    </ul>
    <div class="callout">
      <div class="callout-icon">💡</div>
      <div class="callout-content" data-i18n-html="docsQuickstart.callout1">
        <strong>Don't have Rust?</strong> Install it with:
        <div class="code-block compact">
          <pre><code dangerouslySetInnerHTML={{__html: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`}} /></pre>
        </div>
      </div>
    </div>
  </section>

  <section id="installation">
    <h2 data-i18n="docsQuickstart.installTitle">Installation</h2>

    <h3 id="install-curl" data-i18n="docsQuickstart.instOptionA">Option A: Curl Script (Recommended)</h3>
    <p data-i18n="docsQuickstart.instADesc">The fastest way to install. The script builds a release binary and installs it to <code>/usr/local/bin</code> (or <code>~/.local/bin</code> when a user prefix is used).</p>
    <div class="code-block">
      <div class="code-header">
        <span class="code-lang">bash</span>
      </div>
      <pre><code dangerouslySetInnerHTML={{__html: `curl -sSf https://fathom.uz/install.sh | sh`}} /></pre>
    </div>
    <p data-i18n-html="docsQuickstart.instAFoot">This installs the <code>fathom</code> binary to <code>~/.local/bin</code>. Make sure it's in your <code>PATH</code>.</p>

    <h3 id="install-cargo" data-i18n="docsQuickstart.instOptionB">Option B: Cargo Install</h3>
    <p data-i18n="docsQuickstart.instBDesc">Build from source using Cargo. Requires Rust toolchain.</p>
    <div class="code-block">
      <div class="code-header">
        <span class="code-lang">bash</span>
      </div>
      <pre><code dangerouslySetInnerHTML={{__html: `cargo install --path .`}} /></pre>
    </div>

    <h3 id="install-source" data-i18n="docsQuickstart.instOptionC">Option C: Build from Source</h3>
    <p data-i18n="docsQuickstart.instCDesc">Clone the repository and build locally for development.</p>
    <div class="code-block">
      <div class="code-header">
        <span class="code-lang">bash</span>
      </div>
      <pre><code dangerouslySetInnerHTML={{__html: `git clone https://github.com/yakushevhk/Fathom.git
cd Fathom
cargo build --release`}} /></pre>
    </div>
    <p data-i18n-html="docsQuickstart.instCFoot">The binary will be at <code>./target/release/fathom</code>.</p>
  </section>

  <section id="first-run">
    <h2 data-i18n="docsQuickstart.firstRunTitle">First Run</h2>
    <p data-i18n="docsQuickstart.firstRunSub">Run your first autonomous worker task with a single command. Research is one built-in workflow; the same worker runtime also supports outreach, code, computer use and scheduled operations:</p>
    <div class="code-block">
      <div class="code-header">
        <span class="code-lang">bash</span>
      </div>
      <pre><code dangerouslySetInnerHTML={{__html: `fathom run <span class="code-string">"Find B2B SaaS startups in Berlin with 10-50 employees"</span>`}} /></pre>
    </div>
    <p data-i18n-html="docsQuickstart.firstRunFoot">
      On first run, Fathom will prompt you for your API key if one isn't configured.
      Results are saved to <code>./research-output/</code> by default.
    </p>
  </section>

  <section id="configuration-basics">
    <h2 data-i18n="docsQuickstart.configTitle">Configuration Basics</h2>
    <p data-i18n-html="docsQuickstart.configSub">
      Configuration is stored in <code>~/.fathom/config.toml</code>. All sections are optional — missing fields use defaults.
    </p>

    <h3 id="config-location" data-i18n="docsQuickstart.cfgLocTitle">Config Location</h3>
    <div class="code-block">
      <div class="code-header">
        <span class="code-lang">path</span>
      </div>
      <pre><code dangerouslySetInnerHTML={{__html: `~/.fathom/config.toml`}} /></pre>
    </div>

    <h3 id="config-llm" data-i18n="docsQuickstart.cfgLlmTitle">LLM Section</h3>
    <p data-i18n="docsQuickstart.cfgLlmSub">The only required configuration is your LLM provider settings:</p>
    <div class="code-block">
      <div class="code-header">
        <span class="code-lang">config.toml</span>
      </div>
      <pre><code dangerouslySetInnerHTML={{__html: `<span class="code-section">[llm]</span>
provider    = <span class="code-string">"deepseek"</span>
base_url    = <span class="code-string">"https://api.deepseek.com"</span>
api_key     = <span class="code-string">"sk-your-key"</span>
model       = <span class="code-string">"deepseek-chat"</span>
max_tokens  = <span class="code-number">8192</span>
temperature = <span class="code-number">0.7</span>`}} /></pre>
    </div>

    <h3 id="config-search" data-i18n="docsQuickstart.cfgSearchTitle">Search Backend</h3>
    <p data-i18n-html="docsQuickstart.cfgSearchSub">Choose a search engine for web queries. <code>hybrid</code> uses the first configured backend with results:</p>
    <div class="code-block">
      <div class="code-header">
        <span class="code-lang">config.toml</span>
      </div>
      <pre><code dangerouslySetInnerHTML={{__html: `<span class="code-section">[search]</span>
backend = <span class="code-string">"hybrid"</span>

<span class="code-section">[search.tavily]</span>
api_key = <span class="code-string">"tvly-your-key"</span>`}} /></pre>
    </div>

    <div class="callout">
      <div class="callout-icon">📖</div>
      <div class="callout-content" data-i18n-html="docsQuickstart.callout2">
        See the full <a href="/docs/configuration">Configuration Reference</a> for all available options.
      </div>
    </div>
  </section>

  <section id="tui-mode">
    <h2 data-i18n="docsQuickstart.tuiTitle">TUI Mode</h2>
    <p data-i18n="docsQuickstart.tuiSub">
      Launch the interactive terminal UI for a real-time research experience with progress tracking,
      tool call visualization, and conversation history.
    </p>
    <div class="code-block">
      <div class="code-header">
        <span class="code-lang">bash</span>
      </div>
      <pre><code dangerouslySetInnerHTML={{__html: `fathom tui`}} /></pre>
    </div>
    <p data-i18n="docsQuickstart.tuiFoot">
      The TUI provides an interactive chat interface where you can type queries,
      watch agent progress in real time, and browse results.
    </p>
  </section>

  <section id="http-server">
    <h2 data-i18n="docsQuickstart.httpTitle">HTTP Server Mode</h2>
    <p data-i18n="docsQuickstart.httpSub">
      Start an HTTP API server for programmatic access. Supports REST endpoints and SSE streaming
      for real-time event delivery.
    </p>
    <div class="code-block">
      <div class="code-header">
        <span class="code-lang">bash</span>
      </div>
      <pre><code dangerouslySetInnerHTML={{__html: `fathom serve`}} /></pre>
    </div>
    <p data-i18n-html="docsQuickstart.httpFoot">The server starts on <code>http://localhost:8080</code> by default. Send worker tasks via POST:</p>
    <div class="code-block">
      <div class="code-header">
        <span class="code-lang">bash</span>
      </div>
      <pre><code dangerouslySetInnerHTML={{__html: `curl -X POST http://localhost:8080/api/v1/sessions \\
  -H <span class="code-string">"Content-Type: application/json"</span> \\
  -d <span class="code-string">'{"query": "Find AI startups in London"}'</span>`}} /></pre>
    </div>
  </section>
