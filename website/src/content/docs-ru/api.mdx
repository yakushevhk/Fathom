        <span class="section-label">API для разработчиков</span>
        <h1 class="api-title">Справочник HTTP API</h1>
        <p class="api-description">
          Полный справочник REST API Fathom. Управляйте сессиями автономных воркеров, стримите события и программно управляйте сотрудниками, расписаниями, памятью, управлением и использованием компьютера.
        </p>
      </div>

      {/* OVERVIEW */}
      <section id="overview" class="api-section">
        <h2 class="api-section-title">Обзор</h2>
        <p class="api-text">
          API Fathom — это RESTful плоскость управления для универсальных автономных воркеров. Она управляет сессиями, постоянными сотрудниками, запланированными операциями, памятью, управлением, использованием компьютера и уведомлениями; исследование — один из поддерживаемых рабочих процессов. Все ответы в формате JSON. Стриминговые эндпоинты используют Server-Sent Events (SSE).
        </p>
        <div class="info-block">
          <div class="info-label">Базовый URL</div>
          <code class="info-code">http://localhost:8080</code>
        </div>
        <p class="api-text">
          API поддерживает два метода аутентификации через HTTP-заголовки:
        </p>
        <div class="code-block">
          <div class="code-header">
            <span class="code-lang">HTTP-заголовки</span>
          </div>
          <pre><code set:html={`Authorization: Bearer &lt;your-api-key&gt;
X-Api-Key: &lt;your-api-key&gt;`} /></pre>
        </div>
      </section>

      {/* AUTHENTICATION */}
      <section id="authentication" class="api-section">
        <h2 class="api-section-title">Аутентификация</h2>
        <p class="api-text">
          Когда настроен <code>FATHOM_API_KEYS</code>, запросы API под <code>/api/v1</code> требуют соответствующего Bearer-токена или заголовка <code>X-Api-Key</code>. Без настроенных ключей развёртывания на loopback допускают открытый доступ; привязка сервера к не-loopback адресу требует настройки ключей.
        </p>
        <div class="code-block">
          <div class="code-header">
            <span class="code-lang">Окружение</span>
          </div>
          <pre><code set:html={`FATHOM_API_KEYS=key-abc123,key-def456,key-ghi789`} /></pre>
        </div>
        <p class="api-text">
          Каждый ключ соответствует независимой идентичности. Ограничение частоты применяется на ключ: <strong>120 запросов/минуту</strong> для стандартных эндпоинтов. Превышение лимитов возвращает <code>429 Too Many Requests</code>.
        </p>
        <div class="callout callout-warn">
          <div class="callout-icon">⚠</div>
          <div>
            <strong>Замечание по безопасности:</strong> никогда не раскрывайте API-ключи в клиентском коде или публичных репозиториях. Используйте переменные окружения или менеджер секретов.
          </div>
        </div>
      </section>

              <span>Параметр</span><span>Тип</span><span>Описание</span>
