## Обзор архитектуры

Fathom Bot состоит из двух независимых слоёв: одностраничный чат-клиент (**React 19 + Tailwind + Vite 7**), упакованный в кроссплатформенные десктопные бинарники (**Electron 34** для macOS, Windows и Ubuntu 24.04), и встроенный фоновый **демон-харнесс на Node.js 24**, слушающий `127.0.0.1:8799`.

```
┌─────────────────────────────────────────────────────────────┐
│  Десктопная оболочка (Electron) / Браузерный клиент (PWA)   │
│  React 19 · Zustand Store · Tailwind · Нет прямой сети      │
└──────────────────────────────┬──────────────────────────────┘
                               │ HTTP-команды / SSE-поток
                               ▼
┌─────────────────────────────────────────────────────────────┐
│  Локальный harness-сервер (127.0.0.1:8799)                  │
```

## Ключевые возможности

### 1. Свои CLI агентов
Fathom Bot работает с официальными CLI-бинарниками, установленными на машине оператора (`claude`, `codex`, `grok`, `qwen`, `pi`, `opencode`, `antigravity`). Используются существующие логины и локальные подписки — без промежуточных SaaS-прокси и наценок на токены.

### 2. Рельс провайдеров и выбор модели
Каждому боту в списке можно назначить свой «рассуждающий мозг». Операторы могут переключать движки прямо в разговоре, направлять отдельные задачи на модели с высоким уровнем рассуждений (режим thinking у Claude 3.7 Sonnet, Gemini 3.8) или указывать OpenAI-совместимые кастомные эндпоинты через **Настройки → Движки**.

### 3. Управляемый Computer Use и локальные ВМ
Боты оснащены возможностями действий:
- **Облачные Linux-десктопы:** эфемерные изолированные десктопные контейнеры с живым стримингом экрана и перехватом управления человеком в браузере.
- **Локальные ВМ:** rootless-контейнеры Podman/Docker с XFCE и Cua Driver 0.20.0 со стримингом по noVNC WebSocket.
- **Управление хостом:** опциональная автоматизация ввода на macOS и Ubuntu Xorg, сертифицированная пользователем, с шлюзами разрешений.

### 4. Брокер разрешений и карточки рисков
Все операции с побочными эффектами (выполнение команд в шелле, запись файлов, исходящие сетевые вызовы) останавливаются до исполнения. Брокер разрешений показывает интерактивную карточку в ленте чата, где оператор может нажать **Allow**, **Deny** или скорректировать агента естественным языком.

### 5. Командные каналы с несколькими ботами
Организуйте агентов по контекстным каналам (Работа, Финансы, Юристы, Инженерия). Каждый канал хранит:
- Независимые транскрипты диалогов и общие инструкции (`SOUL.md`).
- Свою рабочую директорию и границы файлов.
- Настраиваемые правила ответов и состав ботов.

### 6. Голосовой режим и звонки ElevenLabs
Полноценные двусторонние голосовые разговоры:
- Озвучивание ответов через ключи ElevenLabs API (markdown переписывается в разговорную форму).
- Нативная диктовка Apple на десктопах macOS.
- Интерактивные полноэкранные голосовые звонки с волновыми формами в реальном времени.

## Структура директорий (`Bot/`)

| Директория | Роль |
| :--- | :--- |
| `Bot/src/` | React 19 SPA: вид чата, раздельный двойной воркспейс, вьюпорт компьютера, выбор модели, палитра команд. |
| `Bot/server/` | Демон-харнесс на Node: адаптеры драйверов движков, шина событий SSE, брокер разрешений, вебхуки. |
| `Bot/server/drivers/` | Драйверы провайдеров, нормализующие ACP, JSON-RPC и CLI stream-JSON в канонические события рантайма. |
| `Bot/electron/` | Нативные оболочки приложений для macOS (.dmg), Windows (.exe) и Ubuntu (.deb / AppImage). |
| `Bot/companion/` | Подключаемые мобильные сервисы-компаньоны для iOS и Android через Tailscale или аутентифицированные туннели. |
| `Bot/deploy/` | Манифесты деплоя: Docker Compose, rootless Podman и reverse-proxy Caddy на периметре. |
| `Bot/docs/` | Подробные технические руководства: кастомные движки, self-hosting, голосовой режим и процедуры верификации. |

## Быстрый старт для разработчика

```bash
# Перейти в директорию Bot
cd Bot

# Установить зависимости
pnpm install

# Запустить локальный harness-сервер (127.0.0.1:8799)
pnpm dev:server

# Запустить фронтенд React Vite (http://localhost:5199)
pnpm dev

# Или запустить десктопную оболочку Electron
pnpm dev:desktop
```

Полные инструкции по сборке пакетов, self-hosting и продакшн-деплою — в [`Bot/README.md`](https://github.com/yakushevhk/Fathom/blob/main/Bot/README.md) и [`Bot/DEPLOYMENT_GUIDE.md`](https://github.com/yakushevhk/Fathom/blob/main/Bot/DEPLOYMENT_GUIDE.md).
