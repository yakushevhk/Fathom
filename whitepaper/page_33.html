Zero Trust Process Isolation: One Sandbox Per Digital Coworker

Deploying autonomous agents that execute shell commands, parse untrusted web payloads, and run browser instances requires kernel-level confinement. In crates/supervisor, Fathom dynamically provisions, governs, and terminates isolated Docker containers with strict security profiles.

Capability Stripping
  • cap_drop: ["ALL"] drops all capabilities.
  • no-new-privileges: true prevents setuid.
  • Read-only root with ephemeral tmpfs.
Resource Sandboxing
  • cgroups v2: 2 CPU cores, 512MB RAM cap.
  • Host daemon protected against OOM.
  • I/O throttled to 50MB/s write maximum.
Ephemeral Volumes
  • Per-job volume mount (/data/workspace).
  • Chromium profile isolated per client.
  • Cryptographic shredding on termination.
