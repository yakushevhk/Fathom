The Evolution of Computer Use: From Brittle Vision to Semantic Trees

Early computer-use agents relied on taking full-screen screenshots and guessing X/Y pixel coordinates—a slow, expensive, and fragile approach that breaks on responsive screens. Fathom controls computers via structured Accessibility Trees (ARIA DOM).

Figure 30.1: Governed Computer Use — Safe pause on 2FA SMS challenge with live operator takeover lease
Accessibility Tree Navigation (ARIA)
  • Tokenized Indexing: Elements receive stable reference tags (@e1, @e2, @e14).
  • Semantic Understanding: Agents see roles: "Button: Submit Order (@e14)".
  • 90% Token Reduction: Snapshots consume ~200 tokens vs 2,000+ for vision models.
Governed Playwright Automation
  • Headless Chromium: Operates in sandboxed containers with isolated session cookies.
  • Anti-Staleness: Verifies element stability before firing clicks or keystrokes.
  • Stealth Evasion: Emulates human mouse curves, scroll pauses, and canvas fingerprints.
Deterministic Computer Interaction: Fathom digital employees operate enterprise portals, QuickBooks, and internal admin dashboards with flawless accuracy and lightning speed.
