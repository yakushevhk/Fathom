Deterministic Safety: The Governance Policy Engine

Deploying autonomous agents in mission-critical enterprise environments requires mathematically provable guardrails. In crates/governance, Fathom implements a fail-closed policy engine where every single tool call is authorized against declarative security rules prior to execution.

1. Declarative Allow / Deny Glob Rules
  • Tool Level: allow: tool="web_search", target="*"
  • Domain Restriction: allow: tool="browser.*", target="https://*.linkedin.com/*"
  • Explicit Admin Deny: deny: tool="browser.type", target="*/admin/*"
  • Destructive Shell Deny: deny: tool="shell", target="rm -rf *"
2. Strict Fail-Closed Security Posture
  • Deny Wins: If an action matches both allow and deny, deny always wins.
  • Default Rejection: Any unclassified tool call fails immediately.
  • Operator Claims: Privileged tools require Ed25519-signed operator claims.
  • Zero Bypass: Enforced at compiled Rust dispatch, immune to prompt hacks.
